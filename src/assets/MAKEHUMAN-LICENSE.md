# mh-body.bin — откуда модель тела

`mh-body.bin` собран скриптом `scripts/makehuman-to-bin.py` из базовой сетки hm08 и файлов форм
(targets) проекта MakeHuman: https://github.com/makehumancommunity/makehuman

Эти ассеты MakeHuman выпущены под **CC0 1.0 Universal** (см. LICENSE.md и LICENSE.ASSETS.md
в репозитории MakeHuman): их можно использовать и менять без ограничений и без указания авторства.
Код MakeHuman (AGPL) в приложение не входит — только данные сетки и форм.
