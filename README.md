# Capsule — капсульный гардероб

Приложение для тебя и друзей: фотографируешь вещи, Gemini вырезает их с фона, а стилист собирает образы на манекене. Ты ставишь «нравится / не нравится» с причинами, и подбор учитывает эти оценки. Кнопка «Что докупить» показывает, каких вещей не хватает капсуле.

Работает в трёх видах из одной кодовой базы:
- **ПК:** сайт, который ставится как приложение (Chrome/Edge → значок «Установить» в адресной строке).
- **Телефоны по ссылке:** то же самое через «На экран Домой». Работает и на iPhone.
- **APK для Android:** собирается автоматически в GitHub Actions.

Основа — [tandpfun/wardrobe](https://github.com/tandpfun/wardrobe) (лицензия MIT, см. `LICENSE`). Что изменено, описано в конце файла.

---

## Как это устроено

```
Телефон / ПК (приложение)  ──код доступа──▶  Cloudflare Worker (proxy/)  ──твой ключ──▶  Gemini API
   вещи, фото, оценки                         проверяет код, лимиты,
   хранятся только на устройстве              пропускает только нужные модели
```

Ключ Gemini лежит только в Cloudflare. В приложении и в APK его нет: у каждого друга свой код доступа, и его можно отозвать.

## Развёртывание (один раз, ~30 минут)

Нужны Node.js 22+ и три бесплатных аккаунта: Google (у тебя AI Pro), Cloudflare и GitHub.

### 1. Ключ Gemini и кредиты AI Pro
1. Открой страницу бенефитов Google Developer Program («My Benefits»), активируй ежемесячные кредиты Google Cloud из подписки AI Pro и привяжи их к платёжному аккаунту Cloud.
2. В Google AI Studio создай API-ключ **в проекте с этим платёжным аккаунтом**.
3. В Google Cloud → Billing → Budgets поставь бюджет-предупреждение, например на $10. Это страховка на случай, если лимиты прокси настроены неправильно.

### 2. Прокси на Cloudflare
```bash
cd proxy
npx wrangler@4 login
npx wrangler@4 kv namespace create USAGE      # скопируй id в wrangler.toml
```
В `proxy/wrangler.toml` замени `PASTE_KV_NAMESPACE_ID_HERE` на этот id и `YOUR_GITHUB_USERNAME` на свой ник GitHub.

```bash
npx wrangler@4 secret put GEMINI_API_KEY      # вставь ключ из AI Studio
npx wrangler@4 secret put ACCESS_CODES        # например: huy:7f3a91c2e8,anna:b41d0e77aa
npx wrangler@4 deploy                         # выдаст адрес https://capsule-proxy.<имя>.workers.dev
```
Коды придумывай длинные и случайные: `openssl rand -hex 8` или любой генератор паролей. Чтобы добавить или убрать друга, заново выполни `secret put ACCESS_CODES` с новым списком.

Модели (`TEXT_MODEL`, `IMAGE_MODEL`) и лимиты задаются в `wrangler.toml` или в панели Cloudflare и меняются без пересборки приложения:
| Переменная | По умолчанию | Смысл |
|---|---|---|
| `DAILY_IMAGE_LIMIT` | 25 | картинок в день на человека |
| `DAILY_TEXT_LIMIT` | 150 | запросов распознавания и стилиста в день на человека |
| `MONTHLY_IMAGE_BUDGET` | 140 | картинок в месяц **на всех вместе**, примерно $10 кредитов |

### 3. GitHub: сайт и APK
1. Создай репозиторий (можно публичный: секретов в коде нет) и загрузи туда эту папку.
2. **Settings → Secrets and variables → Actions → Variables** → добавь переменную `PROXY_URL` с адресом воркера из шага 2.
3. **Settings → Pages → Source: GitHub Actions.**
4. **Actions → «Web app (GitHub Pages)» → Run workflow.** Сайт появится на `https://<ник>.github.io/<репо>/`.
5. **Actions → «Android APK» → Run workflow.** Когда сборка закончится, APK будет в разделе Artifacts (`capsule-apk`). Чтобы APK лежал в Releases с постоянной ссылкой, создай тег: `git tag v1.0.0 && git push --tags`.

## Защита от злоупотреблений
Прокси — **не** открытый доступ к Gemini. Даже с кодом доступа его нельзя использовать как чат-бот или генератор любых картинок:
- есть только задачи гардероба: `detect`, `cutout`, `modeled`, `tryon`, `plan`, `gaps`, `learn`. Прямого прохода к Gemini нет;
- все промпты собирает прокси, приложение присылает только данные: фото, вещи, профиль, короткие тексты;
- модели задаёт сервер (`TEXT_MODEL`, `IMAGE_MODEL`), приложение выбрать модель не может;
- у текстовых запросов есть системная инструкция «только одежда», весь пользовательский текст передаётся как данные в `<user_data>`, ответы жёстко ограничены JSON-схемами, лишнее отбрасывается;
- свободный текст для картинок («Что поправить») сначала проверяется на тему одежды, иначе ответ «Можно писать только про одежду», а картинка не тратится;
- комментарии не про одежду не попадают в память стилиста;
- все тексты обрезаются по длине, картинки проверяются по формату и размеру, лимиты считаются по людям и на всех.

Ограничение: примерка «на мне» работает с любым загруженным фото человека. Gemini сам отклоняет откровенный и вредный контент, но выдавать коды стоит только тем, кому доверяешь.

## Для друзей

**Android (APK):** скачать `capsule.apk`, открыть и разрешить «установку из неизвестных источников» для браузера или файлового менеджера → «Настройки» в приложении → ввести код доступа.

**iPhone и любой телефон (ссылка):** открыть ссылку на сайт → «Поделиться» → «На экран Домой» → «Настройки» → код.

**ПК:** открыть ссылку в Chrome или Edge → значок «Установить приложение» в адресной строке.

Как пользоваться:
1. **Настройки → Мой стиль:** рост, фигура, любимые фасоны и цвета, что не предлагать.
2. **Гардероб → «+»:** фото вещей, по одной на кадр, лучше на однотонном фоне. Для каждой вещи проверяешь кадр, потом вырезанную картинку.
3. **Образы → «Собрать 5 образов»:** оцениваешь каждый, выбираешь причины. Манекен бесплатный, «Примерить на мне» тратит лимит картинок (нужно своё фото в настройках).
4. **«Что докупить»:** список вещей, которых не хватает.
5. **Своими словами:** под оценкой образа можно написать, например, «не люблю бэгги-джинсы, хочу с узкой талией». Стилист превратит это в правило и учтёт в следующих подборах. Правила видны и редактируются в «Настройки → Что запомнил стилист».

Все вещи, фото и оценки хранятся **только на этом устройстве**. Если удалить приложение или очистить данные браузера, гардероб пропадёт.

## Расход
Одна вещь: 1 запрос распознавания + 1 картинка (вырезка) + ещё 1, если включено «фото на мне». Подбор образов и «Что докупить» — это текстовые запросы, они дешёвые. Примерка — 1 картинка. Цены Gemini: https://ai.google.dev/pricing

## Разработка
```bash
npm install
cp .env.example .env     # впиши адрес своего воркера
npm run dev              # http://localhost:5173
npm test                 # тесты прокси и обработки картинок
```

## Что изменено относительно tandpfun/wardrobe
- Сервер на Node (`scripts/import-job-api.mjs`, sharp, папка `data/`) перенесён в само приложение: `src/lib/local-api.js` (те же маршруты), `src/lib/image.js` (тот же алгоритм chroma-key, но на canvas), хранение в IndexedDB. Благодаря этому оно работает как сайт и как APK.
- OpenAI заменён на Gemini через собственный прокси (`src/lib/gemini.js`, `proxy/worker.js`).
- Добавлены: генератор образов с оценками (`src/outfits.jsx`, `src/lib/stylist.js`, `src/lib/mannequin.js`), профиль стиля и настройки (`src/settings-panel.jsx`), русский интерфейс.
- Фото «на тебе» стало необязательным. Убраны скиллы под Codex и IPX-сервер картинок.
- Vite обновлён с 6.4.3 (`npm audit`: high) до 6.4.6.
